SMS Spam Detection 🤖

A Machine Learning project that classifies SMS messages as Spam or Ham (Normal) using TF-IDF and Multinomial Naive Bayes.

Features

- Spam and normal SMS classification
- TF-IDF text vectorization
- Multinomial Naive Bayes
- Interactive Streamlit UI
- Spam/Ham prediction probabilities

Tech Stack

- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

Model Performance

- Accuracy: 96.05%

Run Locally

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run streamlit_app.py

Dataset

SMS Spam Collection Dataset from UCI Machine Learning Repository.

Author

Built as a Machine Learning project to practice NLP and text classification.
